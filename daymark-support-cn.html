极简日历支持

极简日历是一款面向中国大陆用户的原生 macOS 日历与任务管理工具，无需注册或登录即可使用，数据默认保存在本机。

主要功能

  • 月视图、日程、任务、循环规则和本地提醒。
  • 农历与中国大陆节假日显示。
  • ICS、CSV 导入导出，以及 JSON 完整备份与恢复。
  • 深色界面、快捷新建和本机数据存储。

常见问题

是否需要账号？不需要。应用可以离线使用。

数据保存在哪里？默认仅保存在你的 Mac 上。卸载或更换设备前，请先使用 JSON 备份功能保存数据。

提醒没有出现怎么办？请在系统设置中允许“极简日历”发送通知，并在应用设置中确认提醒权限状态。
